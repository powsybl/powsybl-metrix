# Glossary (English ↔ French)

Terminology used for the French translation of the documentation. Keep it consistent across all pages.
Domain terms come from the original French documentation of the Metrix simulator.

|---|---|

| network element (line, transformer...) | ouvrage |
| line | ligne |
| transformer | transformateur |

| generator | groupe de production |
| load | consommation |
| synchronous area | zone synchrone |
| contingency | incident |
| curative action | action curative |
| preventive action | action préventive |
| remedial action (parade) | parade |

| variant | variante |
| base case | cas de base |
| load flow | load-flow |

| adequacy phase | phase d'adéquation (*adequacy phase*) |
| redispatching phase | phase de redispatching (*redispatching phase*) |
| overload / constraint | contrainte |
| flow / transit | transit |
| load shedding | délestage |
| loss of load / network failure | défaillance |
| marginal variation | variation marginale |
| monitored section | section surveillée |
| time series | série temporelle |
